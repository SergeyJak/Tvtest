THREE INDEPENDENT TV PROFILES

Кабинеты ТВ.

Три собственных M3U-источника, три названия и отдельные ссылки для телевизоров.

3 профиля
Как пользоваться: переименуй кабинет, вставь ссылку M3U от своего IPTV-провайдера и сохрани. На карточке появится персональная ссылка для телевизора. При наличии XMLTV ссылка EPG генерируется отдельно. Текущий плейлист и адрес первого кабинета сохранены.
Загружаем профили…

Не публикуй ссылки. Каждая ссылка для телевизора содержит персональный ключ доступа. Исходный M3U-адрес провайдера хранится только на VPS и не выводится обратно в браузер.
EPG / XMLTV

Программа передач для каждого кабинета

EPG берётся из заголовка загруженного M3U или из отдельного XMLTV URL, указанного в карточке. Для каждого кабинета создаётся свой XMLTV с правильными идентификаторами каналов. Если приложение не подтянуло EPG автоматически, вставь его ссылку в настройках плеера.
